# وایرفریم چکاوک یوگا

وایرفریم کلیک‌پذیر نسخه‌ی یک پلتفرم یوگا و حرکت برای مربیان فارسی‌زبان. برای نشان دادن به مربی‌ها در مصاحبه‌های فاز صفر ساخته شده است.

همه‌ی صفحه‌ها موبایل (۳۹۰×۸۴۴) و راست‌چین‌اند. ظاهر عمداً خاکستری است؛ نارنجی فقط برای هشدارها (ریزش شاگرد، ملاحظه‌ی پزشکی) به کار رفته. عددها، اسم‌ها و قیمت‌ها نمونه‌اند و جاهایی که باید پر شوند داخل کروشه آمده‌اند، مثل `[قیمت ترم]`.

## صفحه‌ها

### مسیر شاگرد

| فایل | صفحه |
|---|---|
| `StudentLanding.dc.html` | لندینگ: انتخاب مربی بر اساس نیاز (اصلاح فرم بدن، قدرت، عضله‌سازی، آرامش، انعطاف، کمر و گردن پشت‌میز) |
| `StudentCoachPage.dc.html` | صفحه‌ی فروش مربی و ترم |
| `StudentCheckout.dc.html` | ثبت‌نام و پرداخت |
| `StudentHealth.dc.html` | پرسشنامه‌ی سلامت |
| `StudentSchedule.dc.html` | انتخاب روز و ساعت تمرین و یادآوری |
| `StudentHome.dc.html` | برنامه‌ی من: پیشرفت ترم، جلسه‌ی امروز |
| `StudentPlayer.dc.html` | پخش جلسه با واترمارک، هشدار حرکت حساس، سوال روی لحظه‌ی ویدیو |

### پنل مربی

| فایل | صفحه |
|---|---|
| `Main.dc.html` | داشبورد: جلسه‌های کامل‌شده، فروش، شاگردهای در حال ریزش |
| `CoachTerm.dc.html` | ساخت ترم و جلسه‌ها |
| `CoachUpload.dc.html` | آپلود جلسه و تگ حرکات |
| `CoachStudents.dc.html` | شاگردها، حضور و غیاب، ملاحظات پزشکی |
| `CoachQuestions.dc.html` | صف سوال با پاسخ صوتی |
| `CoachPayouts.dc.html` | درآمد، کمیسیون بر اساس منشأ مشتری، تسویه |

## درباره‌ی فرمت فایل‌ها

فایل‌ها در فرمت `.dc.html` بوم طراحی Claude هستند و به runtime همان بوم (`support.js`) نیاز دارند. اگر مستقیم در مرورگر باز شوند، ممکن است درست نمایش داده نشوند؛ بخش‌های پویا، مثل فیلتر نیازها در لندینگ، بدون آن runtime قطعاً کار نمی‌کنند. `project/canvas.json` جای هر صفحه روی بوم و ترتیب آن‌ها را نگه می‌دارد.
