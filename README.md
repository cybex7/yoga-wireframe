# وایرفریم چکاوک یوگا

وایرفریم کلیک‌پذیر نسخه‌ی یک پلتفرم یوگا و حرکت برای مربیان فارسی‌زبان. برای نشان دادن به مربی‌ها در مصاحبه‌های فاز صفر ساخته شده است.

**پیش‌نمایش:** https://cybex7.github.io/yoga-wireframe/

- فهرست همه‌ی صفحه‌ها: https://cybex7.github.io/yoga-wireframe/
- لندینگ شاگرد: https://cybex7.github.io/yoga-wireframe/StudentLanding.html
- داشبورد مربی: https://cybex7.github.io/yoga-wireframe/CoachDashboard.html
- فرم نظرسنجی مربی‌ها: https://cybex7.github.io/yoga-wireframe/survey.html

همه‌ی صفحه‌ها موبایل (۳۹۰×۸۴۴) و راست‌چین‌اند. ظاهر عمداً خاکستری است؛ نارنجی فقط برای هشدارها (ریزش شاگرد، ملاحظه‌ی پزشکی) به کار رفته. عددها، اسم‌ها و قیمت‌ها نمونه‌اند و جاهایی که باید پر شوند داخل کروشه آمده‌اند، مثل `[قیمت ترم]`.

## ساختار مخزن

| مسیر | چیست |
|---|---|
| `docs/` | نسخه‌ی HTML معمولی همه‌ی صفحه‌ها که GitHub Pages منتشر می‌کند، به‌همراه `index.html` و فرم `survey.html` |
| `apps-script/Code.gs` | اسکریپتی که جواب‌های فرم را در یک Google Sheet ذخیره می‌کند |
| `project/` | فایل‌های اصلی بوم طراحی Claude |

## وصل کردن فرم به Google Sheet

GitHub Pages فقط صفحه‌ی ثابت منتشر می‌کند، پس جواب‌ها در یک Google Sheet ذخیره می‌شوند:

1. یک Google Sheet تازه بساز.
2. از منوی **Extensions › Apps Script**، محتوای `apps-script/Code.gs` را جای کد پیش‌فرض بگذار و ذخیره کن.
3. **Deploy › New deployment** را بزن، نوع را **Web app** بگذار، **Execute as** را «Me» و **Who has access** را «Anyone» کن و Deploy را بزن.
4. آدرسی را که می‌دهد (با `/exec` تمام می‌شود) در `docs/survey.html` جلوی `var ENDPOINT = '';` بگذار و پوش کن.

هر جواب یک ردیف در شیت می‌شود و ردیف اول عنوان ستون‌هاست. فرم را یک بار با اینترنت ایران و بدون فیلترشکن تست کن؛ اگر سرویس‌های گوگل برای مربی‌ها باز نشد، باید به سرور خود شرکت وصلش کرد.

## درباره‌ی فایل‌های بوم

فایل‌های پوشه‌ی `project/` در فرمت `.dc.html` بوم طراحی Claude هستند و به runtime همان بوم (`support.js`) نیاز دارند. اگر مستقیم در مرورگر باز شوند، ممکن است درست نمایش داده نشوند؛ بخش‌های پویا، مثل فیلتر نیازها در لندینگ، بدون آن runtime قطعاً کار نمی‌کنند. `project/canvas.json` جای هر صفحه روی بوم و ترتیب آن‌ها را نگه می‌دارد.
